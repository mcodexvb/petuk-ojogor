# পেটুক অজগর (Petuk Ajogor)

A Bengali 3D browser game: a giant hungry python roams roads, villages, markets and jungle, eating, growing and dodging the police.

**Play:** https://mcodexvb.github.io/petuk-ojogor/

Runs in any modern browser on phone or computer. Single-file game (`index.html`) built with three.js.
